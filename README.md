El objetivo es diseñar e implementar un sistema de comunicación serial bidireccional entre una tarjeta FPGA DE10-Lite y una computadora mediante el protocolo UART. El sistema incorpora un módulo ESP32 que funciona como puente USB-UART para enlazar físicamente ambos dispositivos, además de emplear scripts en MATLAB desde la PC para el envío y recepción de la información. Finalmente, la lógica integrada en la FPGA permite recibir, procesar y transmitir de regreso los datos operando a una velocidad de 9600 baudios.

La carpeta "Suma" cuenta con los módulos empleados para lograr que el número de 8 bits transmitido se devuelva sumándule 1 con ayuda del FPGA; la carpeta "potencia_LUT" contiene los módulos complementarios y modificados para que el FPGA realice una operación al valor de 8 bits transmitidos de elevar a la potencia con factor 3.5 por medio de una LUT preestablecida, de modo que transmita de regreso 32 bits en 4 paquetes de 8 bits con un punto decimal al divir por 10 el valor total recibido.
